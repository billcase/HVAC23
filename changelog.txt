Changelog / Update Notes:
Updated the steel, PVC, and PPR pipe fittings library.
Changed the block counting command from "count" to "countblk" (to fix a command conflict with AutoCAD 2026 and 2027).
Fixed the reducer insertion bug when drawing from a smaller size to a larger size using commands qq1, qq2, and qq3.
Updated the "des" command for copying spreadsheets from Excel into AutoCAD.
Fixed errors in the "tab2excel" and "TabEpr" commands when copying tables from AutoCAD to Excel.
